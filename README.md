# Gates the agents can't skip

Sharing our Harness for AI Delivery and Maintenance. Claude Community talk, Barcelona, by María José Lalama and Vitória Toebe.

Single-file HTML deck (20 slides, ~30 min). Edit `index.html`; served via GitHub Pages.

- Navigate with ← → / space; `F` toggles fullscreen; `R` replays the animations on slides 16 (maintenance) and 17 (where it fits).
- Demo slides (6–12, 14, 15) loop a muted recorded run from `assets/demo/` while the slide is on screen, with a native time bar to scrub. `P` pauses or resumes it; `R` restarts it.
- Print to PDF at 1280×720 for a static copy.
