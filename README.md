# Gates the agents can't skip

Sharing our Harness for AI Delivery and Maintenance. Claude Community talk, Barcelona, by María José Lalama and Vitória Toebe.

Single-file HTML deck (21 slides, ~30 min). Edit `index.html`; served via GitHub Pages.

- Navigate with ← → / space; `F` toggles fullscreen; `R` replays the maintenance animation (slide 19).
- `assets/workflow.mp4` is the 100-second end-to-end video played on slide 3.
- Print to PDF at 1280×720 for a static copy.
